# ContentFactory MCP operation inventory

Live discovery snapshot: 2026-11-08, from the connected Media, Generate and Compose MCP servers, using operations_list with pageSize 100 and following every nextAfterOperationId. Catalog availability depends on configured adapters, provider capabilities and authorization; this snapshot is not the authoritative live catalog. Run operations_list and operations_describe for current schemas, effects, scopes and revisions.

Each endpoint exposes four stable MCP tools: operations_list discovers summaries; operations_describe returns contract revisions and JSON schemas; operations_read invokes a read; operations_execute invokes a write, paid operation or transfer-ticket operation. Use the current exact contractRevision with the full canonical arguments.

Counts: Media 108, Generate 20, Compose 38; six shared content-operation entries occur in both Media and Generate, giving 160 distinct operation IDs. Scope and effects below are the returned compact catalog metadata. Empty effects means no flags were returned, not that an execute operation has no effect.
