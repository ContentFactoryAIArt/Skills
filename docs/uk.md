# Початок роботи з ContentFactory

Створюйте відео, зображення, озвучення, музику й редаговані композиції з AI-агентом у ContentFactory. Інструкції самого скіла написані англійською; спілкуватися та створювати матеріали можна українською.

## Почніть за чотири кроки

1. Установіть Python 3.11 або новішу версію та актуальний Codex CLI. Оберіть наявну папку проєкту.
2. [Завантажте ZIP цього репозиторію](https://github.com/ContentFactoryAIArt/Skills/archive/refs/heads/main.zip) і розпакуйте його або виконайте:

   ```sh
   git clone https://github.com/ContentFactoryAIArt/Skills.git
   cd Skills
   ```

3. З розпакованої або клонованої папки запустіть помічник, указавши шлях до своєї наявної папки проєкту:

   ```powershell
   python scripts/connect.py --workspace "C:\Projects\MyVideo"
   ```

   У macOS або Linux використовуйте `python3` і наявний шлях, наприклад `~/projects/my-video`. Увійдіть у ContentFactory через браузер і виберіть проєкти, дозволи та строк доступу.

4. Відкрийте або перезавантажте проєкт у Codex і напишіть:

   > Використай $contentfactory-video, щоб створити 30-секундне відео про продукт українською. Працюй у вибраному проєкті й покажи план та очікувану вартість до платних операцій.

## Інші MCP-клієнти

Якщо клієнт підтримує віддалений Streamable HTTP MCP з OAuth, додайте `https://content-factory.art/mcp` як один сервер і надайте доступ у браузері. Потім установіть усю папку `skills/contentfactory-video` через штатну функцію скілів клієнта.

## Не вдається підключитися?

Якщо помічник повідомляє, що єдина кінцева точка недоступна, потрібен відповідний випуск сервера ContentFactory. `--install-only` лише готує скіл; для роботи потрібне активне з’єднання. Якщо наявне з’єднання працює, повторний вхід не потрібен.

Докладні поради є в [англомовному посібнику](en.md).

## Фото, відео й 3D з Claude Code

ContentFactory — безкоштовний браузерний редактор фото, відео й 3D. Ваш власний агент також може створювати повноцінні ролики. Генерація та аналіз через ШІ можуть бути платними.

Установіть актуальний Claude Code CLI і виконайте альтернативну команду нижче. Вона встановлює скіл і єдине MCP-підключення. Завершіть авторизацію в браузері та використовуйте /contentfactory-video. Потрібна одна авторизація ContentFactory на клієнт; наявне підключення використовується повторно.

```powershell
python scripts/connect.py --client claude --workspace "C:\Projects\MyVideo"
```
