# ContentFactory के साथ शुरुआत करें

ContentFactory और अपने AI एजेंट से वीडियो, चित्र, वॉइसओवर, संगीत और संपादन योग्य कम्पोज़िशन बनाएँ। स्किल के निर्देश अंग्रेज़ी में हैं; आप हिंदी में बात कर सकते हैं और हिंदी सामग्री बनवा सकते हैं।

## चार चरणों में शुरू करें

1. Python 3.11 या नया संस्करण और नवीनतम Codex CLI इंस्टॉल करें। अपने प्रोजेक्ट के लिए पहले से मौजूद फ़ोल्डर चुनें।
2. [इस रिपॉज़िटरी की ZIP फ़ाइल डाउनलोड करें](https://github.com/ContentFactoryAIArt/Skills/archive/refs/heads/main.zip) और निकालें, या यह कमांड चलाएँ:

   ```sh
   git clone https://github.com/ContentFactoryAIArt/Skills.git
   cd Skills
   ```

3. निकाले या क्लोन किए गए रिपॉज़िटरी फ़ोल्डर से सेटअप कमांड चलाएँ और पथ में अपना मौजूदा प्रोजेक्ट फ़ोल्डर दें:

   ```powershell
   python scripts/connect.py --workspace "C:\Projects\MyVideo"
   ```

   macOS या Linux पर `python3` और `~/projects/my-video` जैसा मौजूदा पथ इस्तेमाल करें। ब्राउज़र में ContentFactory में साइन इन करें और प्रोजेक्ट, अनुमतियाँ तथा पहुँच की अवधि चुनें।

4. Codex में प्रोजेक्ट खोलें या फिर से लोड करें और लिखें:

   > $contentfactory-video से हिंदी में 30 सेकंड का उत्पाद वीडियो बनाएँ। मेरे चुने हुए प्रोजेक्ट में काम करें और सशुल्क काम से पहले योजना व अनुमानित लागत बताएँ।

## अन्य MCP क्लाइंट

यदि आपका क्लाइंट OAuth के साथ रिमोट Streamable HTTP MCP चलाता है, तो `https://content-factory.art/mcp` को एक सर्वर के रूप में जोड़ें और ब्राउज़र में अनुमति दें। फिर क्लाइंट की स्किल सुविधा से पूरा `skills/contentfactory-video` फ़ोल्डर इंस्टॉल करें।

## कनेक्शन में समस्या?

यदि सेटअप बताए कि एकीकृत एंडपॉइंट उपलब्ध नहीं है, तो संबंधित ContentFactory सर्वर रिलीज़ का इंतज़ार करें। `--install-only` केवल स्किल तैयार करता है; रचना शुरू करने के लिए चालू कनेक्शन चाहिए। मौजूदा कनेक्शन ठीक हो तो दोबारा लॉग इन करने की ज़रूरत नहीं है।

विस्तृत समाधान के लिए [अंग्रेज़ी गाइड](en.md) देखें।

## Claude Code से फोटो, वीडियो और 3D संपादन

ContentFactory ब्राउज़र में मुफ्त फोटो, वीडियो और 3D संपादक है। आपका अपना एजेंट पूरे वीडियो भी बना सकता है। AI जनरेशन और विश्लेषण के लिए शुल्क लग सकता है।

नवीनतम Claude Code CLI स्थापित करें और विकल्प के रूप में नीचे का आदेश चलाएँ। यह स्किल और एक MCP कनेक्शन स्थापित करता है। ब्राउज़र में अनुमति पूरी करें और /contentfactory-video इस्तेमाल करें। प्रत्येक क्लाइंट के लिए एक ContentFactory अनुमति चाहिए; मौजूदा कनेक्शन दोबारा उपयोग होता है।

```powershell
python scripts/connect.py --client claude --workspace "C:\Projects\MyVideo"
```
