# ContentFactory менен ишти баштоо

ContentFactory жана AI жардамчыңыз аркылуу видео, сүрөт, үн коштоо, музыка жана түзөтүлүүчү композициялар түзүңүз. Скиллдин ички нускамалары англисче; кыргызча сүйлөшүп, кыргызча материал даярдай аласыз.

## Төрт кадам менен баштаңыз

1. Python 3.11 же андан жаңы версиясын жана актуалдуу Codex CLI орнотуңуз. Мурда эле түзүлгөн долбоор папкасын тандаңыз.
2. [Бул репозиторийди ZIP түрүндө жүктөп алыңыз](https://github.com/ContentFactoryAIArt/Skills/archive/refs/heads/main.zip) жана ачыңыз же төмөнкү буйрукту аткарыңыз:

   ```sh
   git clone https://github.com/ContentFactoryAIArt/Skills.git
   cd Skills
   ```

3. ZIP ачылган же клондолгон репозиторий папкасынан орнотуу жардамчысын иштетип, өз долбооруңуздун бар папкасын көрсөтүңүз:

   ```powershell
   python scripts/connect.py --workspace "C:\Projects\MyVideo"
   ```

   macOS же Linux тутумунда `python3` жана `~/projects/my-video` сыяктуу бар жолду колдонуңуз. Браузерде ContentFactory аккаунтуна кирип, долбоорлорду, уруксаттарды жана кирүү мөөнөтүн тандаңыз.

4. Codex'те долбоорду ачып же кайра жүктөп, мындай деп жазыңыз:

   > $contentfactory-video менен кыргызча 30 секунддук продукт видеосун түз. Мен тандаган долбоордо иште жана акы төлөнүүчү аракеттерге чейин планды жана болжолдуу бааны көрсөт.

## Башка MCP кардарлары

Эгер кардарыңыз OAuth менен алыстан Streamable HTTP MCP колдосо, `https://content-factory.art/mcp` дарегин бир сервер катары кошуп, браузерден уруксат бериңиз. Андан кийин кардардын скилл функциясы аркылуу толук `skills/contentfactory-video` папкасын орнотуңуз.

## Туташууда маселе барбы?

Эгер жардамчы бирдиктүү дарек жеткиликсиз экенин билдирсе, ContentFactory серверинин тиешелүү жаңыртуусу керек. `--install-only` скиллди гана даярдайт; иштөө үчүн активдүү туташуу талап кылынат. Бар туташуу иштеп жатса, кайра кирүүнүн кереги жок.

Кеңири жардам үчүн [англисче нускаманы](en.md) караңыз.
