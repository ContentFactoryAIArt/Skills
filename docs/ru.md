# Начало работы с ContentFactory

ContentFactory — бесплатный браузерный редактор фото, видео и 3D. Подключите
своего агента Codex или Claude Code для редактирования проектов и создания
полноценных роликов. Генерация и анализ через модели могут быть платными:
агент использует ваш бюджет и актуальную оценку стоимости. Подписка на самого
агента оплачивается отдельно.

## Четыре шага для начала

1. Установите Python 3.11+ и актуальный [Codex CLI](https://developers.openai.com/codex/cli)
   или [Claude Code](https://code.claude.com/docs/en/setup). Выберите существующую
   папку проекта. Нужен аккаунт ContentFactory с доступом к проекту: установщик
   не регистрирует аккаунт и не выдаёт права участия.
2. [Скачайте и распакуйте ZIP](https://github.com/ContentFactoryAIArt/Skills/archive/refs/heads/main.zip)
   либо клонируйте `https://github.com/ContentFactoryAIArt/Skills.git`.
3. В папке репозитория выполните **одну** команду для своего клиента:

   ```powershell
   python scripts/connect.py --client codex --workspace "C:\Projects\MyVideo" --language ru
   python scripts/connect.py --client claude --workspace "C:\Projects\MyVideo" --language ru
   ```

   В macOS/Linux используйте `python3` и существующий путь вроде `~/projects/my-video`.
   Завершите вход в браузере, выберите проекты, права и срок доступа.
4. Перезагрузите проект. В Codex вызовите `$contentfactory-video`,
   в Claude Code — `/contentfactory-video`. Например:

   > Исправь экспозицию и цвет выбранной фотографии. Сохрани оригинал и рецепт
   > обработки. Не используй платную генерацию.

   Или:

   > Сделай рекламный ролик на 30 секунд из моих материалов, с титрами, музыкой
   > и 3D-заголовком, если это поддерживается. До платных операций покажи план
   > и стоимость. Сохрани редактируемый таймлайн и отдай готовое видео.

Скилл также охватывает маски, эффекты, векторную графику, обработку звука,
материалы, UV, освещение, Grease Pencil и анимацию Blender. Доступные функции
агент получает с сервера. Инструкции написаны на английском, но общение
и материалы могут быть на вашем языке. Локальные исходники сначала загрузите
через ContentFactory и выберите полученные ассеты.

## Codex: установка скриптом

Скилл устанавливается в `.agents/skills/contentfactory-video` проекта.
Нужна версия Codex с поддержкой `--oauth-client-registration` и
`--oauth-resource`. При первом добавлении сервер запускает штатный OAuth;
второй вход после него не выполняется. MCP-конфигурацией управляет клиент.

## Claude Code: установка скриптом

Передайте `--client claude`. Скилл устанавливается в
`.claude/skills/contentfactory-video`. Сервер добавляется с HTTP-транспортом
и областью `local` — приватно для вас в этом проекте. Затем один раз запускается
`claude mcp login content-factory`. Старую версию без этой команды нужно обновить.
Совместимое подключение сохраняется без повторного входа. Внутри Claude Code
подключением также можно управлять через `/mcp`.

## Другие MCP-клиенты

Единый адрес: `https://content-factory.art/mcp`. Нужны Streamable HTTP,
OAuth/PKCE и динамическая регистрация клиента. Для Media, Generate и Compose
достаточно одной авторизации **на клиент**. При использовании Codex и Claude Code
каждый авторизуется отдельно: токены между ними не копируются. Вход в аккаунт
и согласие на доступ могут занимать разные экраны одного процесса.

## Без повторного входа

Новый диалог или установка инструкций не требуют нового разрешения OAuth.
Установщик сохраняет совпадающее подключение, но не проверяет сохранённый токен.
После установки попросите агента прочитать `projects_list` и возможности
выбранного проекта через единый MCP без платных вызовов. Если список пуст,
создайте/выберите проект в ContentFactory и проверьте проекты в разрешении.

При подтверждённом истечении, отзыве доступа или незавершённом входе:

```sh
python scripts/connect.py --client codex --workspace /path/to/project --login --language ru
python scripts/connect.py --client claude --workspace /path/to/project --login --language ru
```

Выберите команду своего клиента. OAuth показывает инструкции в терминале.
Для ручного входа Claude поддерживает `--no-browser`; Codex — вместе с `--login`.
Если при первой настройке Codex браузер не открылся, прервите её и повторите
с `--login --no-browser`, когда запись сервера уже создана. Не отправляйте в чат
ссылки авторизации или обратного перенаправления.

Старые подключения `/mcp/media`, `/mcp/generate` и `/mcp/compose` имеют другие
OAuth-аудитории. При переходе на `/mcp` один раз потребуется новое согласие.
Сначала проверьте его, затем отключите старые записи. Установщик их не удаляет.
Управление разрешениями: https://content-factory.art/settings/tokens.
Истечение, отзыв и изменение прав проекта могут потребовать повторного входа.

## Проверка и установка без подключения

```sh
python scripts/connect.py --client claude --workspace . --dry-run --language ru
python scripts/connect.py --workspace . --check --language ru
python scripts/connect.py --client claude --workspace /path/to/project --install-only --language ru
```

`--dry-run` не меняет файлы и настройки и не обращается к сети. `--check`
проверяет публичные OAuth-метаданные без входа. `--install-only` устанавливает
только инструкции. Эти режимы не доказывают доступ к проекту или успешность
обработки медиа. Недоступность единого адреса требует исправления сервера;
установщик не подменяет его тремя старыми подключениями.

Чужие серверы и учётные данные не меняются. Конфликтующие настройки и правки
в установленном скилле не перезаписываются. Перед обновлением сохраните свои
правки, удалите только старую папку этого скилла и повторите установку.
Символические ссылки и соединения каталогов не поддерживаются.

## Инструменты и приватность

Творческие операции выполняются только через проверенное подключение ContentFactory.
Четыре MCP-инструмента позволяют находить, описывать, читать и выполнять операции
актуального каталога. Локальная обработка, управление браузером, сторонние MCP
и прямые вызовы провайдеров не используются как замена. Установщик передаёт OAuth
штатному клиенту: он не читает файлы учётных данных, не копирует токены и не печатает
конфигурацию. Права, проекты, срок доступа, бюджет и подтверждения клиента сохраняются.
