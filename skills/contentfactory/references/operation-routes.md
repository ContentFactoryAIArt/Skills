# Find the right ContentFactory operation

Use the relevant row as a discovery path. The names below come from ContentFactory BFF registrations. Query the connected endpoint's `operations_list` and `operations_describe` for current exposure, argument shapes, allowed values and effects. Pass the exact operation revision and complete typed arguments to `operations_read` or `operations_execute`. A capability absent from the connected endpoint needs investigation before any claim of support.

| Outcome | Discover, execute and verify |
| --- | --- |
| Authentic/source footage | Recover the selected project and owned assets. Use [Research](../../contentfactory-research/SKILL.md) for allowed sources and [Assets](../../contentfactory-assets/SKILL.md) for transfer. Verify the actual imported asset/file and its provenance before attaching it. |
| Generated images or moving footage | `generation_models_list` with `projectId`, output kind and intent, followed by `generation_models_describe` for the candidate's opaque `modelId`. Use `generation_preflight` and `generation_create` with `submission`, exact model revision, intent, schema-valid `inputJson` and the declared `sources` bindings. Get the durable result with `content_operation_result_get`. See [video selection and take review](../../contentfactory-generate/references/video.md). |
| Layered or deterministic photo editing | `creative_capabilities` and `photo_process` for processing, `photo_document_capabilities` and `photo_document_get`, `photo_document_save` and `photo_document_render` for a saved editable document. Discover `photo_layered_capabilities` for PSD/PSB interchange. Verify the original, returned revision and rendered pixels or actual layer/mask behavior as requested. |
| Standalone audio | `media_probe` for stream and source, `creative_capabilities` and `audio_process` for an ordered DSP chain, then `media_processing_job_get` for its result. For speech/music/SFX creation, discover `content_operation_preflight` and the matching operation through [Generate](../../contentfactory-generate/SKILL.md). Inspect levels and listen to the changed passage. Retain original and processing parameters for repeatable editing. |
| Video/audio timeline, captions and transitions | `composition_get` and supported layer queries to find stable layer IDs and intervals. Use `composition_capabilities` and applicable caption/motion capability queries, then `composition_edit` with stable targets and expected revision. Preview the changed revision, check nearby cuts and verify the final artifact. |
| Effects on footage or a timeline | Detect whether the operation should edit an existing timeline stack or create a derived file. Discover `composition_effects_list` and `composition_edit` for the former. For the latter discover a dedicated qualified processing operation. If the look only exists on a composition layer, apply it in a scoped editable composition and render the requested range. Preserve order, targets, intervals, keyframes and source pins according to the schemas. Compare the affected range with the prior revision. |
| 3D scene or 2D animation | `blender_model_inspect` for stable nodes/actions on owned GLBs, plus the relevant `blender_*_capabilities` for the actual task. Use `blender_scene_inspect` or `blender_animation_preview` when applicable, then a qualified `blender_animation_render` or `blender_scene_render`. Use `blender_scene_export` for supported editable scene interchange. Review the sequence on the exact staged scene and retain its editable sources. |
| Check and deliver a film | `composition_validate` and `composition_preview` on the intended revision. Use supported `media_probe`, `media_preview` or `media_quality_check` where useful. Render with the exact supported profile and capability revision, recover the final job and `composition_artifact_get`, then perform the [whole-export Gemini audit](quality-audit.md). |

Each row is a starting point. Query narrowly by effect, mask, motion, audio, timeline, display, or Blender feature. Prefer a preserved editable revision for changes the user must be able to revisit. Report gaps by operation, capability, permission or output, with the evidence actually obtained.
