# Creative workspace

Use `$contentfactory` for creative media research, generation, inspection, editing, rendering and project assets/state, including tiny timecode edits. Read its shared SKILL.md and only the relevant domain specialist. If the skill is unavailable in the catalog, locate the installed skill and read it explicitly; do not treat absence from context as permission to bypass it.

The default `contentfactory` orchestrator leads the roles and child skills. For a new video, ad or film, or a substantial creative recut: **screenwriter first, director second, production specialists next**. The screenwriter writes the meaning and general scenes; the director owns filming, staging, performance, action, camera and sound. Before generated video, the director prepares and inspects actual reference frames, then shows a rough storyboard and proposed object placement to the user and waits for explicit approval. Read the installed `contentfactory/references/director-approval.md`. Reuse the same approved package; reapprove material changes to affected beats. This also covers new 3D/2D animation and paid motion tests, without restarting narrow edits using accepted footage. Prefer Seedance 2.5 when available through a live configured compatible route with an authorized quote; discover actual IDs and disclose necessary alternatives.

Video must primarily contain moving scenes. Animate still sources through supported models; when that route cannot deliver, use supported 3D/2D animation with real subject or scene development. Static pictures with text/audio, flat pan/zoom, transitions or moving captions are not the default production format. Still images are rare exceptions with a specific scene purpose and reason, not a fallback for missing footage or failed generation. Preserve factual evidence and existing privacy/spending limits; report an unavailable motion route instead of silently delivering a slideshow. Standalone photo/poster requests remain valid static work.

Always finish a final or revised video with a Gemini quality audit through ContentFactory: submit the complete final video when its duration is <=180 seconds; for longer videos submit ordered video sections covering the whole export with boundary context. This also applies after small edits. Read the installed `contentfactory/references/quality-audit.md`, retain completed reports and actual coverage, fix material defects and audit the corrected final output. Include review in the authorized budget; if Gemini, access, privacy scope or spend blocks it, report the mandatory audit as incomplete instead of claiming completion. Stills and transcripts do not replace this audit.

All creative processing and durable media/project state must use the connected ContentFactory MCP. Do not silently use desktop scripts, FFmpeg/WinRT, other generators, direct provider APIs or another asset store. If an operation or transfer is missing, report the concrete limitation and continue supported work. Local instruction files and requested reports are allowed; they are not an alternate media pipeline.

Resume the selected project and saved creative task; preserve its source pins, stable layer/scene IDs, accepted choices, language, grants, budget and privacy rules. Do not copy private footage or raw messages into logs/memory. Upload and external-model analysis each need authorization within their actual scope; do not re-ask when it already exists.

For a new ad, establish the audience, goal/CTA and source facts; have the screenwriter write the general scenes before the director creates a timed shot rationale and motion plan. Read the advertising reference. For a small revision, read the small-edits reference and change only the relevant interval. Preserve complete speech, stable legible captions, quality sources and coherent transitions. Share the exact final artifact and editable revision; distinguish sampled checks, playback and user acceptance.
