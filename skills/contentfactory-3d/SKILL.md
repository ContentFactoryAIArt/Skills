# contentfactory 3d

Start with the [ContentFactory workflow](../contentfactory/SKILL.md), which defines the required MCP execution, storage, authorization and recovery boundary. Use this specialist for 3D work; an unavailable capability is not permission to substitute a local renderer or another service.

For a new video/film/ad or substantial creative recut, recover the orchestrator's screenwriter-then-director handoff before producing scenes. The [screenwriter](../contentfactory-screenwriter/SKILL.md) owns meaning and general scenes; the [director](../contentfactory-director/SKILL.md) owns filming, staged action, camera and acceptance criteria. If those decisions are absent, route through the shared workflow. A standalone model, still render or narrow scene correction stays scoped to its request.

Use supported authored 3D or 2D animation when a moving-picture shot cannot be realized suitably through video models. Discover the live animation and drawing capabilities, including Blender/Grease Pencil where exposed; do not infer support from this skill's examples. Plan a visible action with a start, development and result, using character/object tracks, drawing changes, deformation, simulation or other supported scene action as appropriate. Camera motion can support that action; a flat picture on a moving plane, pan/zoom, title animation or transitions alone do not satisfy the fallback. Render the complete animation through the supported native job rather than submitting isolated still renders as a substitute. Preserve editable scene sources and return owned moving output to composition. If the necessary animation capability is absent, report the gap to the orchestrator instead of downgrading the production to static pictures with audio.

Inspect the owned source and discover each relevant native capability and its runtime revision before constructing a request. Use supported typed scene and animation inputs; preserve exact source hashes and revisions. Choose output format based on discovered support: editable BLEND, evaluated GLB and rendered media have different fidelity. Cloth simulation's sampled GLBs are static deformations, not animated cloth. Poll the durable media job and verify requested outputs. Review the actual action intervals, continuity and motion in the rendered sequence; endpoint stills do not prove an animation works. If perception is unavailable, report the unreviewed aspects rather than inferring visual quality from job success.
