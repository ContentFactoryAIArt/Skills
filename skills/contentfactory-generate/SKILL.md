# contentfactory generate

Start with the [ContentFactory workflow](../contentfactory/SKILL.md), which defines the required MCP execution, storage, authorization and recovery boundary. Use this specialist for generative work; unavailable pricing, models or imports do not authorize a direct provider or other generation tool.

For a new video, advertisement or film, or a substantial creative recut, recover the orchestrator's handoff: [screenwriter](../contentfactory-screenwriter/SKILL.md) first for meaning and general scenes, then [director](../contentfactory-director/SKILL.md) for filming, staged action, camera, continuity and acceptance criteria. If that handoff is missing, return through the shared workflow before generating production material. Proactively fill identified production gaps within existing authorization and budget, inspect the result against those criteria, and return owned asset references to the orchestrator. A standalone image, sound or narrow generation request does not require a new screenplay.

## Generate movement for moving-picture work

Default to footage with purposeful subject or scene action. A generated still with titles, narration, transitions or a slow pan/zoom is not a completed video scene. Treat still images as references, conditioning sources or a justified brief hold; a predominantly static treatment needs an explicit user request or an agreed creative exception.

When only a still source exists and an animated illustration is appropriate, discover an image-to-video or other compatible video model and animate the action specified by the director. Describe what changes over time, the subject's action and resulting state, continuity, camera behavior and required duration. Keep these directions in the fields actually supported by the selected model's current schema. Select or generate and inspect owned reference frames before submitting generated video; reuse accepted references instead of generating new ones by habit. Bind them through the model's supported conditioning mode and keep unsupported reference slots visible rather than inventing them. These frames are preparation for moving footage, never the final video scene.

If model animation is unavailable, unsuitable or still fails after bounded attempts, recover uncertain receipts and switch the shot to supported authored [3D/2D animation](../contentfactory-3d/SKILL.md) through ContentFactory. Request real object, character, drawing or scene action; moving a flat picture or adding animated text does not satisfy the fallback. Preserve the beat's purpose and report an unavailable animation capability instead of silently delivering a slideshow. Existing authentic footage remains suitable; generated animation cannot establish real product behavior, an event or a customer result.

Check feasibility of any required downstream editable format, alpha/mask or timeline handoff with the relevant specialist before paid generation; a generated flattened image alone does not fulfill a layered-editing request.

List and describe current model or voice selections for the requested modality; do not invent provider IDs, supported parameters or prices. Image/video requests require both the envelope operation's `contractRevision` and the selected model's separate `modelContractRevision`; build `inputJson` against that model's schema and source slots. `image_foreground_extract` generates a person on a plain white background; it is not a pixel-exact alpha mask and does not provide transparency. Use `generation_preflight` for compatible image/video requests and `content_operation_preflight` for compatible speech, music and effects. A preflight validates and quotes; it does not submit or reserve funds. Count spent, reserved and uncertain amounts against the user's budget. Preserve the idempotency key for an identical command; if execution is uncertain, poll its durable receipt and reconcile charges before retrying. Reuse returned owned file references in later workflows. Distinguish an unavailable tariff, insufficient balance and an over-budget quote.

`PRICING_UNAVAILABLE` or `NOT_CONFIGURED` is an admission blocker, not evidence that funds were spent or that the account balance is insufficient. Repeating an unchanged preflight does not repair it; recheck after a relevant tariff, selection or deployment change. On an idempotency conflict, recover the earlier command and compare its exact inputs before choosing whether this is recovery or a new command. A failed result import may follow completed provider work and a settled charge; reconcile receipt, charge and output state before retrying. For a requested person's likeness or cloned voice, retain the authorized original source and reject a generated candidate that fails likeness or intelligibility review.
